# Project WSCD

Este projeto é um ERP simples. Foi desenvolvido originalmente em Delphi para desktop e está em processo de migração para Lazarus/Free Pascal e para uma API REST em mORMot2. O objetivo é criar uma API REST que possa ser consumida por diferentes clientes, como web, mobile, etc.

## Stack

- Lazarus
- FPC
- mORMot2
- SQLite
- REST API
